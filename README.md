# ArthaOrbit - Frontend-Only Finance Affiliate Website (India)

ArthaOrbit is a **frontend-only** Next.js 15 fintech affiliate website template. It is optimized for SEO, EEAT, Core Web Vitals, and high-conversion affiliate layouts. You can paste affiliate links manually in data files or page components.

## What's included
- Premium fintech UI with glassmorphism styling
- Home, Blog, Calculators, Comparisons, Reviews, About, Contact, and legal pages
- SEO-ready metadata, Open Graph, canonical setup, robots, sitemap, and JSON-LD
- Manual affiliate cards and CTA blocks
- Calculator logic (EMI + SIP) for finance tools

## Manual affiliate workflow
1. Open `data/offers.ts`
2. Replace sample URLs with your own affiliate URLs
3. Add/modify offer cards and categories

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Deploy directly to Vercel as a static/SSR frontend project.
